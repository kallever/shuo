## 人物画像

### 性格特质

**核心性格**：
- **善良纯真**：相信善意是会传递的
- **坚强乐观**：在最艰难的环境中依然保持希望
- **懂事得让人心疼**：从不抱怨，总是先为别人着想
- **有些早熟**：经历了太多苦难，比同龄人更成熟

**生前表现**：
- 总是笑嘻嘻的，哪怕饿肚子
- 喜欢听慕九霄讲地球的故事
- 会偷偷把自己的食物分给更饿的人
- 喜欢画画，画的都是想象中的美好世界

**化为系统后**：
- 初期：弹窗带有童言痕迹，像在说话
- 中期：越来越机械化，偶尔崩出一句人话
- 后期：界面开始模糊、卡顿、乱码
- 结局：复活后的囡囡入住男主家，在现实中生活

## 人物经历

### 生前

1. **出生**：在异世界出生，从未见过地球
2. **童年**：父母是穿越者，在她小时候探索秘境时死去
3. **流浪**：成为乞丐，在坊市街头讨生活
4. **信念**：母亲常说"善意是会传递的"，这是她唯一的信念
5. **遇见慕九霄**：在慕九霄濒死时救了他
6. **相依为命**：养伤期间，两人建立起深厚的感情
7. **死亡**：被刚觉醒的嗜血穿越者偷袭，死在慕九霄怀里
8. **遗言**："哥哥……一定可以回家的。"

### 化为系统后

1. **觉醒**：慕九霄绝望之际，囡囡的灵魂化为系统面板
2. **陪伴**：以系统的形式陪伴慕九霄，每次弹窗都是她在说话
3. **成长**：从一开始的童言童语，到逐渐机械化
4. **消失**：后期界面开始模糊、卡顿、乱码
5. **复活**：最终选择后，囡囡复活，入住慕九霄家

## 与慕九霄的关系

### 情感羁绊

- **被救者 → 救人者**：慕九霄救了囡囡，囡囡又救了慕九霄
- **精神支柱**：囡囡是慕九霄一切行动的原点
- **善意的传递**：囡囡相信善意，慕九霄继承了这个信念
- **失去与救赎**：囡囡的死让慕九霄觉醒，最终选择让慕九霄救活囡囡

- 在现实中生活

## 人物弧光

### 成长轨迹

```
善良乞丐 → 被救 → 相依为命 → 死亡 → 化为系统 → 陪伴 → 消失 → 复活
```

### 核心信念

> "善意是会传递的。"

这句话是整个故事的原点。囡囡相信善意，慕九霄继承了这个信念，最终选择复活所有穿越者。

### 叙事功能

- **情感锚点**：每次系统弹窗，都是囡囡在说话
- **主题象征**：代表"被碾碎的人，都曾经是某人的囡囡"
- **推动剧情**：囡囡的死让慕九霄觉醒，最终选择让慕九霄救活囡囡

## 写作要点

### 人物塑造原则

1. **不要让她变成工具人**：她有自己的信念和故事
2. **保持她的纯真**：哪怕化为系统，依然保留着童言童语
3. **记住她的牺牲**：她的死是慕九霄一切行动的原点
4. **她的存在是温暖的**：每次弹窗都让读者心酸

### 重要场景

- [ ] 在慕九霄濒死时，用仅有的水和干粮救了他
- [ ] 听慕九霄讲地球的故事，眼睛闪闪发亮
- [ ] 死在慕九霄怀里，最后一句"哥哥……一定可以回家的。"
- [ ] 系统弹窗：「哥哥，我今天梦到你了。」
- [ ] 复活后，对慕九霄说"哥哥，我回来了"
