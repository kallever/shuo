## 人物画像

### 性格特质

**核心性格**：
- **外冷内热**：表面冷漠，内心渴望温暖
- **坚强独立**：不依赖任何人，习惯独自承担
- **细腻敏感**：观察力极强，能察觉别人的情绪变化
- **压抑自我**：为了控制体质，长期压抑情感

**表面形象**：
- 冰山美人，不苟言笑
- 说话简洁，不废话
- 独来独往，不合群
- 对所有人都保持距离

**真实内心**：
- 渴望被爱，但不敢靠近任何人
- 想谈一场甜甜的恋爱，但体质不允许
- 对慕辰有好感，但每次都提醒自己不能动情
- 偶尔会羡慕那些能自由表达情感的人

- **保持距离**：与人交谈时会不自觉后退半步
- **情绪控制**：从不大笑大哭，表情管理极好

- **完美主义**：做事追求极致，不容许瑕疵
- **偷偷关心**：会默默关注在意的人，但不会表达

## 能力体系

### 月寒渊体

**核心能力**：
- **引月华寒气**：可引动月光中的寒气为己用
- **凝冰为刃**：寒气可化为各种冰刃进行攻击
- **冰封领域**：情绪激动时会释放冰封之力，冻结周围一切

**代价**：
- 情绪波动即会失控
- 动情时冰封之力暴走
- 长期压制情感，内心越来越空洞
- 若不完善，会被法则侵蚀，彻底失去感情

**成长路径**：
1. 初期：只能被动释放，无法控制
2. 中期：学会初步运用，可以主动召唤寒气
3. 后期：找到平衡点，既能动情又能控制体质

### 战斗风格

- **前期**：远程攻击为主，保持距离
- **中期**：近战与远程结合，攻守兼备
- **后期**：冰封领域全开，以一敌多

## 人物弧光

### 成长轨迹

```
压抑自我 → 遇见慕辰 → 动情挣扎 → 体质暴走 → 找到平衡 → 深爱 → 失去 → 被救活
```

### 关键转折点

1. **初遇慕辰**：第一次对一个人产生好奇
2. **体质暴走**：为了救慕辰，情绪失控，差点冻结一切
3. **对黑暗人格说"君子论迹不论心"**：动摇了黑暗人格
4. **最终被杀**：让慕辰彻底绝望
5. **被时间之力救活**：第二人生

### 核心信念

> "想要被爱，但不敢靠近。"

苏凌的悲剧在于：她想要的是"被爱"，但慕辰给的是"并肩作战"——两人的需求错位，直到慕辰真正失去她，才知道自己在意什么。
