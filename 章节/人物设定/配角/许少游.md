## 人物弧光

### 成长轨迹

```
精明算计 → 穿越 → 适应弱肉强食 → 背叛 → 活到最后 → 看到慕辰的选择
```

### 核心信念

> "弱肉强食是唯一的规则。"

许少游代表了另一种选择：不是所有人都要追求善意，有些人只相信弱肉强食。

### 叙事功能

- **对比**：与慕辰形成对比，代表"弱肉强弦"的选择
- **制度产物**：他是灵息贷世界观的产品——制度制造出来的怪物
- **反思**：让读者思考善恶的边界

---

## 写作要点

1. **不要让他变成纯粹的坏人**：他有自己的逻辑
2. **保持他的精明**：他不是蠢，是选择了不同的路
3. **记住他的最后一句话**：让读者思考善恶的边界
4. **他的结局是值得思考的**：不是被秒杀，而是活到最后，看到慕辰的选择
