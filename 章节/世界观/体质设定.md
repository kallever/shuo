# 玄体谱

穿越者自带天赋体质，需要特定条件激活，各有各的机缘和诅咒。

---

## 太初冥体（慕辰 & 魔神）

主角和最终反派拥有同一种体质，一脉同源，走向却截然不同。

**慕辰的表现**

| 项目 | 内容 |
|------|------|
| 能力 | 黑暗能量化**太初冥铠**（防御）和**太初冥刃**（攻击） |
| 核心特性 | 濒死时急速自愈，战力暴涨数倍，**每次永久保留一半增幅** |
| 代价 | 每次濒死觉醒同步强化体内的黑暗人格 |
| 激活条件 | 极端情绪冲击（囡囡之死） |
| 备注 | 有天赋但不够狠，总把自己逼到绝境，负面人格逐渐登场 |

**魔神的表现**

| 项目 | 内容 |
|------|------|
| 能力 | 灭世之力，不死不灭 |
| 特性 | 杀不死，只能被镇压 |
| 状态 | 被某位存在镇压无数年，等待释放 |

## 月寒渊体（苏凌）

| 项目 | 内容 |
|------|------|
| 能力 | 引月华寒气，凝冰为刃 |
| 代价 | 情绪波动即会失控，动情时冰封之力暴走 |
| 现状 | 一直压制情绪，不敢动情，如月悬寒渊 |
| 风险 | 若不完善，会被法则侵蚀，彻底失去感情|

| 项目 | 内容 |
|------|------|
| 能力 | 以血为食，饮血可瞬间恢复并暴涨战力 |
