# 世界观设定

---

## 零、众神的试炼

### 真相
这个世界是众神的试炼场。并非自然形成，而是被更高维度的存在创造，用于观察、娱乐或某种未知目的。

### 观测机制
- **时间流速差异**：试炼世界与现实世界的时间流速不同，现实世界一天可能对应试炼世界数月
- **片段式观测**：现实世界只能看到试炼世界的片段，无法实时追踪，也无法干预
- **弹幕互动**：现实世界的观测者可以发送弹幕，但试炼世界的人看不到、也感知不到
- **众神视角**：众神可以看到更多，但似乎也在遵循某种规则，不能直接干预

### 现实世界的反应
- **失踪事件**：大量平民在短时间内神秘消失，引发社会恐慌
- **官方调查**：各国政府机构秘密调查失踪原因，成立特别部门
- **民间猜测**：有人认为是集体幻觉，有人认为是外星绑架，有人认为是超自然现象
- **死亡不回归**：失踪者若在异世界死去，尸体不会出现在现实世界，但这个人在现实中依然存在过——有家人，有朋友，有失踪前的痕迹
- **时间悖论**：由于时间流速差异，失踪者有时会"回来"，但已经过去很久，导致社会关系混乱

### 试炼世界的影响
- **被观察感**：偶尔有人会感到莫名的"被注视感"，但无法确认
- **弹幕幻觉**：极少数敏感者偶尔会听到模糊的"声音"，但很快消失
- **众神干预痕迹**：天衡府的某些"古籍"中记载着无法解释的现象，暗示有更高存在

> 这个设定为故事增加了元叙事层——读者（现实世界）在看小说，小说里的人也在被"观看"。慕九霄的挣扎不仅是为了生存，也是在被无数双眼睛注视着。

## 一、天衡府（原名"机构"）

### 创立
- 数百年前，由七位顶尖大能联手创建
- 初衷：维持天地秩序，保护凡人不受秘境暴乱波及
- 当时是天下的救世主，万民敬仰

### 演变
- 权力逐渐集中，制度腐化
- 从"守护者"→"管理者"→"垄断者"→"食人者"
- 最初的七位大能陆续陨落或失踪，继任者一代不如一代

> 天衡府的堕落不是一夜之间，而是每一项"临时措施"最终变成了"制度"。

### 组织架构

**最高层**
- **九位府尊** — 天衡府最高决策者
- 其中有大能后代，也有从底层爬上来的
- 内部并非铁板一块，分保守派和激进派

**核心分府**

| 分府 | 职能 |
|------|------|
| **衡察院** | 招募穿越者和本地修士，分配任务 |
| **衡钥阁** | 制造、保管、发行秘钥 |
| **衡息阁** | 灵息贷的放贷与催收 |
| **衡刑司** | 维持秩序，追杀叛逃者 |
| **衡矿司** | 管理灵矿，监督欠债者挖矿 |
| **绛渊** | ⚠️ 秘密分府，负责血奴圈养和精血提取 |
| **藏经阁** | 收录功法、神通、古籍 |
| **四方院** | 对外交涉，各城管理 |

### 地方分布
- 总府设在世界中央的**天阙城**
- 各大城池设有分府，分府主由府尊指派
- 偏远地区控制力较弱，也是黑市和叛逃者的温床

## 二、修炼九境

此世界的修炼体系以**灵息**为核心。灵息是天地间最本源的灵气，也是秘境产出的根本资源。修行者通过不断精炼灵息来突破境界。

### 九境

| 境界 | 说明 | 寿元 | 突破所需灵息 |
|------|------|------|-------------|
| **启灵** | 开启灵觉，感知灵息。大部分穿越者止步于此 | 60-80年 | — |
| **锻骨** | 灵息淬炼筋骨血脉，脱胎换骨 | 120-150年 | ~1000 |
| **凝元** | 灵息凝聚化为真元，贯通经脉 | 200-300年 | ~1万 |
| **结丹** | 真元压缩至极限，凝结成丹，战力质变 | 400-500年 | ~10万 |
| **育婴** | 金丹破碎，孕育元婴，可短距离瞬移 | 600-800年 | ~50万 |
| **出窍** | 元婴可离体遨游，神识外放 | 1000年左右 | ~200万 |
| **归真** | 返璞归真，元婴与肉身彻底合一 | 1500-2000年 | ~500万 |
| **合道** | 与天地法则共鸣，举手投足蕴含规则之力 | 3000年左右 | ~2000万 |
| **登极** | 修行极致，渡劫飞升 | 5000年左右 | ~1亿 |

> 穿越者的体质和天赋会影响修炼速度。有人十年结丹，有人百年仍在启灵。
> 突破所需灵息为**基础消耗**，不含丹药、功法、秘钥等额外开支。

### 灵息与灵石

- **1块下品灵石 = 100灵息**
- 灵石分下品、中品、上品、极品四级，每级100倍
- 1块中品灵石 = 100下品灵石 = 10000灵息
- 1块上品灵石 = 100中品灵石 = 100万灵息
- 1块极品灵石 = 100上品灵石 = 1亿灵息
- 灵息更适日常交易，灵石多用于大额支付和修炼

### 修炼资源
- **灵息** — 修炼的根基资源，也是货币
- **灵石** — 灵息凝结的固体，高纯度灵息
- **丹药** — 炼丹师炼制，辅助突破瓶颈
- **功法** — 修炼法门，决定上限
- **神通** — 特殊战斗技，机缘获取

## 三、秘境

秘境是天衡府统治的根基。所有修炼资源皆源于此。

### 类型

| 类型 | 成因 | 特征 | 风险 |
|------|------|------|------|
| **天然秘境** | 天地自然形成 | 地貌各异的独立空间，有灵脉灵植 | 低~中 |
| **灵宝秘境** | 古代修士遗迹 | 洞府、宗门遗址，藏功法神通法器 | 中~高 |
| **灵异秘境** | 空间异变或能量污染 | 法则扭曲，不可预测 | 极高 |

> 秘境**刷完不刷新**，但会刷新新的秘境，资源有限。外围已被搜刮殆尽，越深越危险，机缘也越大。

### 等级划分

| 等级 | 对应境界 | 说明 |
|------|---------|------|
| **玄级** | 启灵~锻骨 | 最外层，如雾里看花，初显神秘 |
| **幽级** | 锻骨~凝元 | 中层，如幽谷深潭，暗藏凶险 |
| **冥级** | 结丹 | 深层，如幽冥之地，大恐怖伴大机缘 |
| **墟级** | 育婴以上 | 核心，如上古遗迹，埋藏着绝迹之物 |
| **荒级** | 归真以上 | 传说之地，九死一生，多已关闭失传 |

### 特殊现象
- 秘境之间偶尔会产生**空间裂痕**，互相连通
- 秘境可能**游移**——入口位置随机出现和消失
- 秘境会**排斥**超过其等级上限的修行者进入
- 秘境深处常有**守境者**（远古异兽或禁制傀儡）

### 秘境内的真正危险——人

秘境最危险的不是妖兽和禁制，是**同行的人**。

- 还不起贷款的人会铤而走险，在秘境里埋伏抢夺别人的收获
- 有人组队进去，出来时只剩一个人——没人管，也没法查
- 天衡府的态度：**秘境里面发生的事，与天衡府无关**
- 秘钥卖出即止，是死是活各凭本事

> 这就是为什么慕九霄第一次重要任务就被队友背刺——不是他运气差，是这个世界就是这样运行的。

## 四、秘钥

进入秘境的唯一凭证。天衡府的绝对垄断命脉。

### 等级

| 等级 | 对应秘境 | 价格（灵息） |
|------|---------|------------|
| **骨钥** | 玄级秘境 | 100灵息 |
| **石钥** | 幽级秘境 | 1000灵息 |
| **玉钥** | 冥级秘境 | 10000灵息 |
| **珀钥** | 墟级秘境 | 100000灵息 |
| **星钥** | 荒级秘境 | 有价无市 |

### 特性
- 由**衡钥阁**统一铸造，每把刻有唯一印记
- 每把秘钥有**使用次数**（1~10次不等，越高级次数越多）
- 多把低级秘钥可**融炼合成**高级秘钥（技术被衡钥阁垄断）
- 秘钥本身可**辅助修炼**——吸收其中封存的灵息，相当于直接获取灵息
- 非天衡府渠道的秘钥（如李老的破针），每一把都是逆天机缘

### 核心逻辑：过路费
- 私人持有秘钥 = 死罪
- 黑市流通的秘钥都是天衡府故意"漏出"的，量极少且价格恐怖
- **天衡府赚的不是利息，是过路费**——只要有人进秘境就得买钥匙，稳赚不赔
- 新人没本钱才需要贷款，有资本后直接买钥匙，不用再借
- 天赋者攒够本钱就能跳出去，没天赋的永远原地踏步——不是天衡府刻意压榨，而是**你的产出刚好只够糊口**

## 五、灵息契（原名灵息贷）

### 基本机制
- 灵息只能在秘境中获取
- 新人没钱买初始秘钥 → 签灵息契 → 进秘境赚第一桶金 → 还贷
- 年息 **两成（20%）**，复利计算
- 正常情况：借100灵息买骨钥 → 秘境赚200-500 → 还贷后剩几十到三百 → 再买骨钥循环 → 几次后攒够本金

### 风险在哪
- 秘境有**死亡率**——如果死在秘境里，贷款不用还（天衡府认亏）
- 如果没死但**亏了**（收获不够还贷）→ **利息滚雪球**
- 滚雪球的人不是常态，但数量足够多，养活了整个绛渊

### 违契后果

| 后果 | 说明 |
|------|------|
| **灵矿苦役** | 送入衡矿司下属灵矿挖矿抵债，每日定额 |
| **绛鼎奴** | 有特殊体质者被秘密送入绛渊 |
| **归墟** | 杀死，灵魂被抽走，用于维持禁制法阵 |

> 灵息契不是人人必踩的陷阱，而是**第一块垫脚石**。踩过去了就是过路客，踩不过去就是养料。

### 底层生态

- 大部分穿越者一辈子都攒不够买高级秘钥的钱
- 他们最终会选择**放弃**——找个角落娶妻生子，做回凡人
- 也有部分人不甘心，铤而走险去抢——这些人就是秘境里最大的威胁
- 天衡府对此完全放任：**只要你不妨碍我卖钥匙，你杀人放火与我无关**
- 整个底层就是一个养蛊场——有天赋的爬上去，没天赋的烂在底下，凶狠的吃掉老实的

## 六、衡矿司（灵矿）

- 天衡府控制下的灵石矿区
- 违契者被强制送去做矿工
- 工作环境恶劣，塌方和异兽袭击是家常便饭
- 部分矿坑深处有**异变灵石**——是灵异秘境的起源之一
- 矿工中偶尔有人挖到宝物私藏——慕九霄后期机缘的潜在来源

---

## 七、绛渊（血奴）

- 特殊体质者在违契后的最终下场
- 由机密分府**绛渊**管理，位置不公开
- 流程：圈养 → 定期抽血 → 精血提取 → 最终枯竭而死
- 精血用途：
  - 炼制**绛血丹**（突破瓶颈的禁药）
  - 维持**某种古老禁制**
  - 供给**某位存在的续命**（伏笔）
- 一旦送入绛渊，几乎没有生还可能
- 天衡府对外完全否认绛渊的存在

> 萧凝霜的冰封体质若暴露，会被绛渊盯上。
> 绛渊的真相是慕九霄后期与天衡府彻底决裂的关键导火索。

## 八、穿越者

### 真相
穿越者并非随机现象，而是被众神选中的"试炼者"。他们来自地球，是现实世界失踪人口的一部分。

### 特征
- 均来自地球，但穿越时间和地点各异
- 穿越时自带**天赋体质**，需要特定条件激活
- 穿越者的灵魂带有异界印记，天衡府可凭此追踪
- 部分穿越者隐约有"被选中"的感觉，但无法证实

### 现状
- 部分人已生儿育女，完全融入此界
- 部分人始终想回家（如慕九霄）
- 极少数顶尖者已进入天衡府高层
- 三万穿越者中，突破凝元者不足十分之一

### 与现实世界的联系
- 穿越者在现实世界的"失踪"引发调查
- 由于时间流速差异，穿越者在试炼世界度过数年，现实世界可能只过去数月
- 极少数穿越者偶尔会梦到现实世界的片段，但以为是幻觉
- **死亡不回归**：穿越者若在异世界死去，尸体不会出现在现实世界，但这个人在现实中依然存在过

## 九、语言与命名说明

为区别于传统修仙小说命名：
- 修炼九境为"启灵→锻骨→凝元→结丹→育婴→出窍→归真→合道→登极"
- 秘境等级以"玄幽冥墟荒"命名，取自神秘程度由浅至深
- 秘钥等级以"骨石玉珀星"命名，取自材质从凡到神
- 天衡府的分府命名取"衡"字为纲，暗喻"公平"实则"失衡"
- 秘密分府"绛渊"独立于衡字体系，暗示其游离于规则之外
