# 神通设定

---

## 神通机制

### 基本规则

- 神通分为**本命神通**和**外界神通**两大类
- 本命神通：体质自带，别人无法学习
- 外界神通：可获取、学习、传授，需要天赋和修炼
- 有人学不会可以转手卖出
- **组合学习**：学会多个低级神通可组合成高级神通

### 等级划分

| 等级 | 说明 | 获取难度 |
|------|------|---------|
| **凡级** | 基础神通，威力一般 | 低 |
| **灵级** | 较强神通，威力可观 | 中 |
| **地级** | 强大神通，可越级战斗 | 高 |
| **天级** | 顶级神通，威力恐怖 | 极高 |
| **仙级** | 传说中的神通，可毁天灭地 | 几乎不可能 |

## 二、外界神通（学习类神通）

> 参考西游记，可获取、学习、传授，需要天赋和修炼。

### 神通收集机制

**秘境与神通**：
- 每个秘境中有1-2个地煞七十二术的传承
- 主角需要不断探索秘境收集神通
- 这个过程是中期核心内容（神通篇200章）

**竞争机制**：
- 部分秘境有**独立钥匙**（不归天衡府管）
- 独立钥匙会被竞争者争夺
- 有些秘境**已被他人捷足先登**，神通已被拿走
- 主角会遇到：空手而归、与人争夺、被人截胡等情况

**主角武器**：
- **武器类型**：棍
- **可由天赋加强**：太初冥体可强化棍的威力
- **成长路线**：普通铁棍 → 灵器棍 → 宝器棍 → 仙器棍
- **神通搭配**：棍法 + 太初冥刃 = 冥刃棍法

## 四、神通与战斗

### 战斗原则

1. **神通不是万能的**：需要配合战斗技巧和策略
2. **神通有代价**：使用过度会疲惫，甚至反噬
3. **神通可成长**：随着修炼，威力逐渐增强
4. **神通可组合**：多个神通组合使用效果更好

### 战斗示例

**慕九霄战斗风格**：
- 前期：太初冥铠防御 + 太初冥刃攻击 + 濒死自愈保命
- 中期：加入筋斗云身法 + 五雷正法远程攻击
- 后期：七十二变变化 + 太初冥刃 + 雷冥斩组合 + 散功法阵

**萧凝霜战斗风格**：
- 前期：引月华寒气 + 凝冰为刃，远程攻击
- 中期：凌波微步身法 + 冰封领域控制
- 后期：冰封万里组合 + 寒冰禁锢控制
