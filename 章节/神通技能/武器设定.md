# 武器设定

---

## 武器机制

### 基本规则

- 武器是**战斗工具**，与神通不同
- 可由炼器师炼制，也可在秘境中获取
- 等级越高，威力越强，但需要更高的修为才能驾驭
- 武器可与神通配合，发挥更大威力

### 等级划分

| 等级 | 说明 | 获取难度 |
|------|------|---------|
| **凡器** | 普通武器，无特殊效果 | 低 |
| **灵器** | 有灵性，可与主人心意相通 | 中 |
| **宝器** | 威力强大，可越级战斗 | 高 |
| **仙器** | 传说中的武器，可毁天灭地 | 几乎不可能 |
| **神器** | 神明使用的武器，超越一切 | 不可能 |

#### 太初冥刃（神通化形）

| 项目 | 内容 |
|------|------|
| **类型** | 神通化形武器 |

## 武器与战斗

### 战斗原则

1. **武器不是万能的**：需要配合战斗技巧和策略
2. **武器有等级**：等级越高，威力越强，但需要更高的修为才能驾驭
3. **武器可成长**：随着主人修炼，威力逐渐增强
4. **武器可组合**：多个武器组合使用效果更好

### 战斗示例

**慕辰战斗风格**：
- 太初冥刃（神通化形）+ 太初冥铠（防御）
- 不依赖实体武器，以神通为主

**苏凌战斗风格**：
- 月寒剑（攻击）+ 冰晶手链（辅助控制）
- 实体武器与神通结合

## 武器与剧情

### 关键剧情点

1. **获得武器**：主角在秘境中获得武器
2. **炼制武器**：苏凌炼制月寒剑
3. **武器暴走**：苏凌体质暴走，月寒剑失控
4. **武器对决**：慕辰与敌人用武器对决
5. **武器成长**：随着修炼，武器威力逐渐增强

### 武器与情感

- **囡囡的遗物**：破旧地图，指向秘境钥匙
- **老陈的遗物**：破针，与地图配套
- **苏凌的遗物**：冰晶手链，母亲的遗物

## 写作要点

1. **不要让武器变成万能的**：需要配合战斗技巧和策略
2. **保持武器的等级**：等级越高，威力越强，但需要更高的修为才能驾驭
3. **记住武器的成长**：随着主人修炼，威力逐渐增强
4. **武器与情感结合**：让武器成为情感的载体
