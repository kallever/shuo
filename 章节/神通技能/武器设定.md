# 武器设定

---

## 武器机制

### 基本规则

- 武器是**战斗工具**，与神通不同
- 可由炼器师炼制，也可在秘境中获取
- 等级越高，威力越强，但需要更高的修为才能驾驭
- 武器可与神通配合，发挥更大威力
- **武器不能升级**，需要去秘境或交易拿到更好的

### 等级划分

| 等级 | 说明 | 获取难度 |
|------|------|---------|
| **凡器** | 普通武器，无特殊效果 | 低 |
| **灵器** | 有灵性，可与主人心意相通 | 中 |
| **宝器** | 威力强大，可越级战斗 | 高 |
| **仙器** | 传说中的武器，可毁天灭地 | 几乎不可能 |
| **神器** | 神明使用的武器，超越一切 | 不可能 |

## 主要武器

### 慕辰的武器

#### 棍（主武器）

**核心设定**：
- 棍**不能升级**，需要去秘境或交易拿到更好的棍
- 太初冥体天赋可**强化棍的威力**
- 棍与太初冥刃结合，形成独特战斗风格

**棍的获取方式**：
- 秘境探索获取
- 交易市场购买
- 击败敌人缴获
- 前人遗物

**战斗风格变化**：

| 阶段 | 棍的来源 | 战斗风格 |
|------|---------|---------|
| **前期** | 秘境获取普通棍 | 谨慎保守，以防御为主 |
| **中期** | 交易/秘境获得灵器棍 | 开始主动进攻，棍法+神通 |
| **后期** | 秘境获得宝器/仙器棍 | 大开大合，以力破巧 |

## 武器与战斗

### 战斗原则

1. **武器不是万能的**：需要配合战斗技巧和策略
2. **武器有等级**：等级越高，威力越强，但需要更高的修为才能驾驭
3. **武器不能升级**：需要去秘境或交易拿到更好的
4. **武器可组合**：多个武器组合使用效果更好

### 战斗示例

**慕辰战斗风格**：
- 太初冥刃（神通化形）+ 棍（实体武器）
- 不依赖实体武器升级，以神通为主
- 太初冥刃可附着在棍上，增加棍的威力

**苏凌战斗风格**：
- 月寒剑（攻击）+ 冰晶手链（辅助控制）
- 实体武器与神通结合

## 武器与剧情

### 关键剧情点

1. **获得武器**：主角在秘境中获得武器
2. **炼制武器**：苏凌炼制月寒剑
3. **武器暴走**：苏凌体质暴走，月寒剑失控
4. **武器对决**：慕辰与敌人用武器对决
5. **武器成长**：随着修炼，武器威力逐渐增强

### 武器与情感

- **囡囡的遗物**：破旧地图，指向秘境钥匙
- **老陈的遗物**：破针，与地图配套
- **苏凌的遗物**：冰晶手链，母亲的遗物

## 写作要点

1. **不要让武器变成万能的**：需要配合战斗技巧和策略
2. **保持武器的等级**：等级越高，威力越强，但需要更高的修为才能驾驭
3. **记住武器不能升级**：需要去秘境或交易拿到更好的
4. **武器与情感结合**：让武器成为情感的载体
