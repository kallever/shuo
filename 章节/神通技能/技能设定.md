# 技能设定

---

## 技能机制

### 基本规则

- 技能是**战斗技巧**，与神通和武器不同
- 可通过修炼习得，也可通过实战积累经验
- 等级越高，威力越强，但需要更高的修为才能施展
- 技能可与神通和武器配合，发挥更大威力

### 等级划分

| 等级 | 说明 | 获取难度 |
|------|------|---------|
| **基础技能** | 基础战斗技巧，威力一般 | 低 |
| **进阶技能** | 较强战斗技巧，威力可观 | 中 |
| **高阶技能** | 强大战斗技巧，可越级战斗 | 高 |
| **顶级技能** | 顶级战斗技巧，威力恐怖 | 极高 |
| **传说技能** | 传说中的战斗技巧，可毁天灭地 | 几乎不可能 |

## 技能与战斗

### 战斗原则

1. **技能不是万能的**：需要配合神通和武器
2. **技能有等级**：等级越高，威力越强，但需要更高的修为才能施展
3. **技能可成长**：随着修炼，威力逐渐增强
4. **技能可组合**：多个技能组合使用效果更好

### 战斗示例

**慕辰战斗风格**：
- 暗影步（身法）+ 冥刃斩（攻击）+ 冥铠护身（防御）
- 以技能为主，配合神通

**苏凌战斗风格**：
- 冰影步（身法）+ 月寒斩（攻击）+ 冰封护罩（防御）
- 技能与神通结合

## 技能与剧情

### 关键剧情点

1. **习得技能**：主角在秘境中习得技能
2. **技能暴走**：苏凌体质暴走，技能失控
3. **技能对决**：慕辰与敌人用技能对决
4. **技能代价**：使用技能过度，付出代价
5. **技能成长**：随着修炼，技能威力逐渐增强

### 技能与情感

- **囡囡的死**：让慕辰习得暗影步
- **苏凌的体质**：让慕辰明白她的痛苦
- **黑暗人格**：让慕辰面对内心的黑暗面

---

## 写作要点

1. **不要让技能变成万能的**：需要配合神通和武器
2. **保持技能的等级**：等级越高，威力越强，但需要更高的修为才能施展
3. **记住技能的成长**：随着修炼，威力逐渐增强
4. **技能与情感结合**：让技能成为情感的载体
